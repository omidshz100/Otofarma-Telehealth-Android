# روند پروژه Otofarma

سه پروژه جدا هستند. فقط از راه API بکند به هم وصل می‌شوند.

1. بکند، FastAPI
2. داشبورد، وب
3. اپ اندروید، همین پوشه

هر قدم را همین‌جا تیک می‌زنیم. اول بکند، بعد داشبورد، بعد تکمیل اپ اندروید.

## قفل شده

- [x] سه پروژه جدا: بکند، داشبورد، اپ اندروید.
- [x] Admin فقط داشبورد است. نام، ایمیل و رمز داشبورد دارد.
- [x] کاربر دستگاه: نام، نقش، Gmail، رمز Gmail، رمز اپ، و اپ‌های تیک‌خورده.
- [x] نقش فقط برچسب است و فهرست اپ را تعیین نمی‌کند.
- [x] Gmail را Admin خودش می‌سازد. بکند صندوق ایمیل نمی‌سازد. مشخصات را ذخیره می‌کند و فقط Admin می‌بیند.
